# Presentación SEOSA + Nueva Minería

Sitio estático (sin build) listo para Vercel.

- `index.html`: toda la presentación. Cada lámina empieza con un comentario
  `<!-- ===== Lámina N: nombre ===== -->`; el texto se edita directo ahí.
- `img/`: fotos. Para cambiar una foto, reemplaza el archivo manteniendo el mismo nombre.

Navegación:
- Flechas grandes a los costados de la pantalla.
- Clic en cualquier parte de la lámina: avanza (clic en el tercio izquierdo: retrocede).
- Teclado: flechas, espacio, Enter, Re Pág/Av Pág; F = pantalla completa.
- Rueda del mouse o trackpad.
- En celular: deslizar a la izquierda o derecha.
- Barra inferior con puntos: clic en un punto para saltar a esa lámina (al pasar el mouse muestra su título).
Se puede abrir en una lámina específica con `#N` al final de la URL (ej. `/#5`).
